Drop launchpad logos here. Wraith uses a file automatically when it exists, and falls back to its built-in mark when it does not.

Names (lowercase), either .svg or .png (square, at least 64x64, transparent background is best):
  pumpfun.svg   (or pumpfun.png)   -> pump.fun
  bonk.svg      (or bonk.png)      -> LetsBonk
  bags.svg      (or bags.png)      -> Bags
  boop.svg      (or boop.png)      -> boop.fun
